## Featured Project

### [Prepo — AI-Powered Career Coach](https://github.com/shivanshgupta-tech/prepo)

A full-stack Generative AI-powered career preparation platform designed to help users improve their professional skills and prepare for job opportunities.

**Key Features:**

- AI-powered resume builder
- Personalized cover letter generation
- AI-generated mock interviews and assessments
- Performance tracking and improvement insights
- Personalized industry insights and career recommendations
- Secure authentication and user management

**Tech Stack:** Next.js, React.js, Gemini AI, PostgreSQL, NeonDB, Prisma, Clerk, Inngest, Tailwind CSS and shadcn/ui.
